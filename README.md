# Wedding OS

> 결혼 준비를 한 곳에서 — 우리 둘만의 결혼식 시스템.
> 결정·청첩장·식전영상·체크리스트까지 한 도메인에서.

웨딩플래너 없이 직접 결혼식을 준비하면서 만든 도구를 정리한 모노 앱입니다. 한 번 셋업하면 내 결혼식에 그대로 쓸 수 있어요.

---

## 세 가지 방법으로 시작할 수 있어요

### 📱 1) 내 휴대폰에 저장 — 가장 쉽고 빠르게

가입·로그인 없이 바로 시작. 모든 정보는 **내 기기에만** 저장됩니다.

→ [demo.weddinghub.app](https://demo.weddinghub.app) (예정)

장점: 가입 불필요 · 안전
단점: 청첩장 공유 불가 · 둘이 따로 편집 불가

### 🌐 2) 우리만의 결혼식 웹사이트 만들기 — 진짜 청첩장처럼

무료 서비스 두 곳(Supabase + Vercel)에 가입해 우리 부부 전용 사이트를 띄웁니다.

장점: 청첩장 링크 카톡 공유 · 부부 동시 편집 · 하객 RSVP
단점: 약 15분짜리 셋업 가이드 따라하기 필요

앱 안에서 한 단계씩 안내해드려요.

### 💻 3) 코드 받아 마음대로 고치기 — AI에게 시켜서

레포를 통째로 받아서 Claude Code, Cursor 같은 AI 도구에 던지면 **내 결혼식 식대로** 손볼 수 있어요. 색깔·디자인·기능 전부 자유.

```bash
git clone https://github.com/commet/wedding-os.git
cd wedding-os
npm install
npm run dev
```

이후 `CLAUDE.md` 또는 `AGENTS.md` 를 AI 도구에 함께 던지세요.

## 들어 있는 것들

- 🏠 **대시보드** — D-day, 진행률, 급한 일
- ✅ **체크리스트** — 7~8개 카테고리, 우선순위, 마감일
- 💍 **결혼반지** — 25개 브랜드 카탈로그, ★/♥ 듀얼 좋아요, 가격 신선도
- 🏨 **호텔** — OTA 가격 비교, AI에게 검색 요청
- ✈️ **항공권** — 멀티시티 비교
- 🏝️ **신혼여행** — 후보지 탭, 일정·예산·메모

- 🎥 **식전영상** — 5막 구조 + AI 자연어 편집 (풀 에디터는 별도)

## AI 비용은 본인이 부담하지 않습니다

기본적으로 모든 AI 기능은 **챗봇 다리 모드**로 동작합니다:
1. 도구가 ChatGPT/Claude/Gemini에 그대로 붙여넣을 프롬프트를 자동 생성
2. 사용자가 챗봇 무료 버전에 복붙
3. 답변을 도구에 다시 붙여넣으면 자동 반영

진짜 자주 쓸 사람은 [Settings → AI 키]에서 본인 Anthropic API 키를 입력하면 챗봇 단계를 생략할 수 있어요.
